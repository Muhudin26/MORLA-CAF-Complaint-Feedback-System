IMPORTANT LIMITATIONS:
1. This is a static GitHub Pages starter. WhatsApp and email buttons open the user's app with a prepared message; the user must press Send.
2. The dashboard only reads local browser storage on the same device/browser. It is not a shared online database.
3. A QR code must point to the final published website URL. Generate the final QR after GitHub Pages is published; a QR image cannot be reliably finalized before the public URL is known.
4. Do not put confidential customer information into a public repository. For a shared dashboard/database, connect a backend such as Supabase or Firebase and add access control.
5. For public deployment, consider renaming admin.html or adding proper authentication before using any real customer data.
